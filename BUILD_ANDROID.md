# Local developer build — macOS ARM64

**Reference device: AYN Thor.** See [reference configuration](docs/REFERENCE_DEVICE.md); observations on other hardware are unverified.

Install Python 3.14+, JDK 21, Android SDK platform/build-tools 35, Android NDK, CMake, Ninja, .NET 10, SPIRV-Tools and glslang (`glslangValidator`). Set ANDROID_HOME, ANDROID_NDK_HOME and JAVA_HOME explicitly.

Create a virtual environment and install the pinned Python requirements:

```sh
python3 -m venv publication-work/venv
source publication-work/venv/bin/activate
pip install -r requirements.txt
```

 Start from your own decrypted, merged Z-A 2.0.2 dump: ExeFS containing main, sdk, rtld, main.npdm and an extraction-manifest.json generated by the supplied extract_exefs.py; raw merged romfs.bin. No keys or game input are supplied. Alternatively, use the command-line NSP importer below; there is no in-app NSP installer.

Run:

```sh
python tools/prepare_za.py --exefs /absolute/path/to/exefs --romfs /absolute/path/to/romfs.bin
bash android/game_activity/build_apk.sh
```

The script writes private game-derived data into ../Uitgepakt beside the repository. Keep this directory private. The resulting APK is local output only and must never be published. For test coverage and remaining device checks, see [VALIDATION.md](VALIDATION.md).

The runtime uses /data/local/tmp/za-android-202 on Android. It needs main.patched.bin, sdk.patched.bin, romfs.bin and runtime-index.bin directly inside that device directory, plus the shared-fonts subdirectory. Device installation and driver choice are manual; no personal environment, driver, save or shader seed is included. The native translator builds from source and can generate missing shaders locally.

## Private system fonts and device installation

Z-A also needs six shared system fonts from your own firmware dump. These are private inputs, never repository files. Extract them locally with:

```sh
python games/totk/scripts/extract_shared_fonts.py --firmware /absolute/path/to/firmware-ncas --keys /absolute/path/to/prod.keys --output /absolute/path/to/private-shared-fonts
python tools/install_za.py --serial DEVICE_SERIAL --fonts /absolute/path/to/private-shared-fonts
python tools/install_za.py --serial DEVICE_SERIAL --fonts /absolute/path/to/private-shared-fonts --apply
```

The first installation command prints a plan; the second installs the APK and transfers your private input. No game starts automatically. Keep your local signing key to install future builds over this one. A differently signed build may not update an existing installation; do not uninstall an existing app without backing up its saves.

For the 1080p / 60-FPS configuration reported in the README, the private device `env` file uses `TOTK_OPERATION_MODE=docked` and `ZA_FPS60=1`. The code defaults to handheld operation if no override is supplied. Other settings, driver choice and scene complexity affect performance. The install helper preserves existing environment settings and does not automatically create this file.

## Starting from your own NSP files

The command-line importer takes a base game NSP (or XCI), the supported update NSP and your own key file. It verifies the update ExeFS against the supported hashes, merges the base/update RomFS with integrity checks, verifies the resulting image against the reference hash, and prepares private runtime data. It does not build or install an APK.

```sh
python tools/import_nsp.py --base /absolute/path/to/base.nsp --update /absolute/path/to/update.nsp --keys /absolute/path/to/prod.keys
```

The first invocation fetches a pinned hactool source revision and builds the project's bounded-input/private-key-file adaptation using Git, make and clang. That dependency requires network access; no game input is sent. `--hactool /absolute/path/to/hactool` uses an existing build with those project hooks instead. A stock unmodified hactool is insufficient. Allow at least 20 GiB of temporary space in addition to the input files and build dependencies.

Private inputs/outputs remain in ignored `publication-work/` (and, for Z-A, the adjacent `Uitgepakt/` directory). Use a fresh checkout for a new import; the importer refuses to overwrite existing work. `--exefs-only` stops after verifying the executable dump, leaving a partial import for diagnostics; use a fresh checkout for the full workflow afterwards. There is no in-app importer.

The distributed `games/totk/assets/shader_list.tsv` is intentionally empty. Optional Mac seed generation discovers shaders from your own dump; no collected game identifiers or cache are bundled. The Android local translator handles variants encountered during play.
